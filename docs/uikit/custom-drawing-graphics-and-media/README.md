# Custom Drawing, Graphics, and Media

Custom graphics are role-specific depth. Study this topic when a role involves
image-heavy feeds, data visualization, media editing, or bespoke rendering.

## Preparation Paths

- **Rapid review:** Learn when to choose view drawing, shape layers, or prepared
  images. Know why full-size image decoding can cause memory spikes.
- **Standard preparation:** Complete the first two concepts for rendering and
  image-pipeline judgment.
- **Role-specific depth:** Add blur and advanced compositing for highly visual
  products. Move to Core Image or Metal only when UIKit and Core Animation no
  longer fit the workload.
