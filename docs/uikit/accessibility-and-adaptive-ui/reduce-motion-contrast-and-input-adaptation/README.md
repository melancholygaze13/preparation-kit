# Reduce Motion, Contrast, and Input Adaptation

> An adaptive screen responds to the user's accessibility settings and input
> method. Important meaning and actions must not depend only on motion, color,
> precise pointer movement, or touch timing.

## Quick Recall

- Check Reduce Motion before using large movement, parallax, or motion-only
  transitions.
- Use color and contrast preferences as inputs to design, not as afterthoughts.
- Do not make color the only signal for state, error, or selection.
- Support touch, keyboard, pointer, VoiceOver, and Switch Control paths where
  the feature needs them.
- Listen for relevant accessibility setting changes when the screen can remain
  visible while preferences change.
