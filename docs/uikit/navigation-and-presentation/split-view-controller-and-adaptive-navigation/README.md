# Split View Controller and Adaptive Navigation

> A split view controller presents related navigation columns and adapts them as
> space changes. The model should preserve selection and route meaning even when
> columns collapse.

## Quick Recall

- Split navigation fits master-detail and sidebar-detail workflows.
- Columns are presentation of navigation state, not the state itself.
- Compact widths may collapse columns into a stack-like experience.
- Selection state should survive resizing and scene restoration.
- Use split navigation when simultaneous context helps the task.
