# Compositional Layouts and List Configuration

> Compositional layout builds collection views from sections, groups, and items.
> Modern list configuration uses collection views to get table-like behavior
> with collection-view flexibility.

## Quick Recall

- Compositional layout describes each section independently.
- Items live in groups; groups live in sections.
- Use estimated sizes for self-sizing content.
- List configuration gives collection views table-style rows, headers, and
  accessories.
- Choose layout structure from content and scrolling behavior, not from visual
  novelty.
