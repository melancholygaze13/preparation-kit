# Animation, Transitions, and Interaction

## Preparation Paths

- **Rapid review:** Study property animators, transition contexts, interruption,
  cancellation, and Reduce Motion behavior.
- **Standard preparation:** Complete the first three concepts in learning-path
  order.
- **Role-specific depth:** Add drag and drop, context menus, and haptics for
  document, productivity, input-heavy, or iPad-focused roles.

## Learning Path

1. [Property Animators and Animation Options](property-animators-and-animation-options/README.md)
2. [View Controller Transitions and Coordinators](view-controller-transitions-and-coordinators/README.md)
3. [Interactive Animations and Interruption](interactive-animations-and-interruption/README.md)
4. **Optional role-specific depth:**
   [Drag and Drop, Context Menus, and Haptics](drag-drop-context-menus-and-haptics/README.md)
