# Auto Layout and Adaptive Layout

Auto Layout is core UIKit interview material because it connects view geometry,
dynamic content, localization, safe areas, and trait changes. A strong answer
should explain constraints as relationships, not as final frames.

## Learning Path

### Rapid Review

1. [Constraints, Anchors, and Priorities](constraints-anchors-and-priorities/README.md)
2. [Intrinsic Content Size, Hugging, and Compression](intrinsic-content-size-hugging-and-compression/README.md)

### Standard Preparation

3. [Layout Guides, Safe Areas, and Margins](layout-guides-safe-areas-and-margins/README.md)
4. [Trait Collections, Size Changes, and Adaptation](trait-collections-size-changes-and-adaptation/README.md)

### Role-Specific Depth

Use the trait and size-change material when the role involves iPad, multitasking,
Mac Catalyst, complex forms, or design-system ownership.
