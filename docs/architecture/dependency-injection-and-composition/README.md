1. [Constructor and Protocol Injection](constructor-and-protocol-injection/README.md)
2. [Composition Roots and Object Graphs](composition-roots-and-object-graphs/README.md)

## Preparation Paths

- **Rapid review:** Read all four concept overviews, then rehearse the short answers
  about constructor injection, roots, scopes, and locator trade-offs.
- **Standard preparation:** Complete all four bundles in learning order. They cover
  the dependency and object-graph decisions expected in senior iOS interviews.
- **Role-specific depth:** Staff and Principal candidates should focus on shared API
  ownership, graph tooling, concurrency-safe scopes, test standards, and migration.
