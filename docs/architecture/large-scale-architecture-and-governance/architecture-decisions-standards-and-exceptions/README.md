# Architecture Decisions, Standards, and Exceptions

> Record significant decisions with their context and costs, turn repeated decisions into
> narrow standards, and allow owned exceptions. Governance should speed common choices
> while preserving local authority where system-wide consistency adds no value.

## Quick Recall

- Match decision scope to impact and reversibility.
- Record context, options, decision, consequences, owner, and review trigger.
- Standardize repeated cross-team risks, not personal preferences.
- Automate rules that can be checked reliably.
- Give every exception a reason, owner, risk control, and expiry.
