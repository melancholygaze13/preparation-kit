## Learning Path

1. [Feature and Layer Module Boundaries](feature-and-layer-module-boundaries/README.md)
2. [Interfaces, Implementations, and Dependency Inversion](interfaces-implementations-and-dependency-inversion/README.md)

4. [Cross-Team Ownership and API Evolution](cross-team-ownership-and-api-evolution/README.md)

## Preparation Paths

- **Rapid review:** Read all four concept overviews, then rehearse the short answers
  about boundary axes, interface modules, graph cycles, and API migration.
- **Standard preparation:** Complete all four bundles in learning order. They cover
  the core modularization decisions expected in senior iOS interviews.
- **Role-specific depth:** Staff and Principal candidates should focus on graph and API
  governance, build telemetry, team ownership, compatibility, and migration programs.
