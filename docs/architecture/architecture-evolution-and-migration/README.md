# Architecture Evolution and Migration

## Learning Path

1. [Incremental Replacement and Compatibility Boundaries](incremental-replacement-and-compatibility-boundaries/README.md)
2. [Migration Sequencing and Dependency Untangling](migration-sequencing-and-dependency-untangling/README.md)
3. [Rollout, Observability, and Reversal](rollout-observability-and-reversal/README.md)
4. [Deprecation, Standards, and Team Coordination](deprecation-standards-and-team-coordination/README.md)

## Preparation Paths

- **Rapid review:** Read the four overviews and rehearse incremental replacement,
  migration ordering, rollout gates, and deprecation ownership.
- **Standard preparation:** Complete all four bundles in order. They cover how to change
  architecture without a risky all-at-once rewrite.
- **Role-specific depth:** Staff and Principal candidates should focus on cross-team
  sequencing, compatibility windows, operational signals, and removal accountability.
