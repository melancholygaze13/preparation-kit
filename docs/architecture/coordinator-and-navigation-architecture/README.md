# Coordinator and Navigation Architecture

## Learning Path

1. [Navigation Ownership and Flow Boundaries](navigation-ownership-and-flow-boundaries/README.md)
2. [Child Coordinators and Lifetime](child-coordinators-and-lifetime/README.md)
3. [Deep Links, Restoration, and Navigation State](deep-links-restoration-and-navigation-state/README.md)
4. [MVVM-C and State-Driven Navigation](mvvm-c-and-state-driven-navigation/README.md)

## Preparation Paths

- **Rapid review:** Read all four concept overviews, then rehearse the short answers
  about flow ownership, child teardown, deep links, and navigation state.
- **Standard preparation:** Complete all four bundles in learning order. They cover
  the coordinator and navigation decisions expected in senior iOS interviews.
- **Role-specific depth:** Staff and Principal candidates should focus on feature route
  contracts, multiple scenes, restoration compatibility, migration, and ownership.
