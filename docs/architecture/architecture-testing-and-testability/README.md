# Architecture Testing and Testability

## Learning Path

1. [Test Boundaries and Confidence](test-boundaries-and-confidence/README.md)
2. [Test Doubles, Contracts, and Integration](test-doubles-contracts-and-integration/README.md)
3. [Architecture Rules and Dependency Enforcement](architecture-rules-and-dependency-enforcement/README.md)
4. [Testing Navigation, State, and Side Effects](testing-navigation-state-and-side-effects/README.md)

## Preparation Paths

- **Rapid review:** Read the four concept overviews, then rehearse the short answers
  about test boundaries, contract tests, dependency rules, and deterministic effects.
- **Standard preparation:** Complete all four bundles in learning order. They cover how
  architecture creates fast feedback without losing confidence at real boundaries.
- **Role-specific depth:** Staff and Principal candidates should focus on shared test
  infrastructure, dependency-policy enforcement, suite health, and cross-team contracts.
