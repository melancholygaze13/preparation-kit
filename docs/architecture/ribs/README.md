# RIBs

RIBs is a framework for organizing large mobile applications as a tree of business-logic
scopes. It is role-specific depth for teams that use RIBs or need cross-platform,
tool-supported architecture for many independently owned features.

## Learning Path

1. [Router, Interactor, Builder, and Component](router-interactor-builder-and-component/README.md)
2. [RIB Trees, Lifecycle, and Scoping](rib-trees-lifecycle-and-scoping/README.md)
3. [Testability, Tooling, and Adoption](testability-tooling-and-adoption/README.md)

## Preparation Paths

- **Rapid review:** Read the three overviews and learn the role split, tree lifecycle,
  and dependency scoping model.
- **Standard preparation:** Complete all bundles when the target team names RIBs or has a
  large nested-state mobile architecture.
- **Role-specific depth:** Focus on child attachment, scoped dependencies, leak detection,
  code generation, and incremental adoption.
