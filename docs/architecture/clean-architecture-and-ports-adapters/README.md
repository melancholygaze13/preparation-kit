# Clean Architecture and Ports and Adapters

## Learning Path

1. [Dependency Rule and Use-Case Boundaries](dependency-rule-and-use-case-boundaries/README.md)
2. [Ports, Adapters, and Protocol Ownership](ports-adapters-and-protocol-ownership/README.md)
3. [Boundary Models and Data Mapping](boundary-models-and-data-mapping/README.md)
4. [Pragmatic Layering and Adoption Cost](pragmatic-layering-and-adoption-cost/README.md)

## Preparation Paths

- **Rapid review:** Read all four concept overviews, then rehearse the short answers
  about dependency direction, port ownership, mapping, and proportional adoption.
- **Standard preparation:** Complete all four bundles in learning order. They cover
  the Clean Architecture decisions expected in senior iOS architecture interviews.
- **Role-specific depth:** Staff and Principal candidates should focus on module and
  contract ownership, incremental migration, compatibility, standards, and measurement.
