## Preparation Paths

- **Rapid review:** Read each core concept overview, then rehearse its interview
  short answers. Add Model-View only for a SwiftUI-focused loop.
- **Standard preparation:** Complete all four core bundles in learning order, then
  study the Model-View bundle as a common high-priority application.
- **Role-specific depth:** Staff and Principal candidates should focus on boundary
  enforcement, cross-team ownership, migration cost, and architecture standards.
