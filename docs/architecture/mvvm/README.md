# MVVM

## Learning Path

1. [View, View Model, and Model Responsibilities](view-view-model-and-model-responsibilities/README.md)
2. [Inputs, Outputs, Bindings, and Observation](inputs-outputs-bindings-and-observation/README.md)
3. [Async Work, Lifecycle, and Cancellation](async-work-lifecycle-and-cancellation/README.md)
4. [View Model Scope and Composition](view-model-scope-and-composition/README.md)

## Preparation Paths

- **Rapid review:** Read all four concept overviews, then rehearse the short answers
  about responsibilities, bindings, task ownership, and view-model scope.
- **Standard preparation:** Complete all four bundles in learning order. They cover
  the core MVVM design and concurrency decisions expected in senior iOS interviews.
- **Role-specific depth:** Staff and Principal candidates should focus on composition
  roots, shared-state ownership, cross-feature navigation, standards, and migration.
