# Existentials, Composition, and Delegation

> A generic parameter preserves one concrete type per call.
> An `any Protocol` existential stores a runtime value behind the protocol interface.

## Quick Recall

- Generics preserve one concrete type through a call.
- `any Protocol` stores different conforming values behind one interface.
- Delegation needs a clear ownership and lifetime contract.
